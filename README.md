# K45movies GitHub Pages demo

Serve this directory as static files. The demo uses a curated sample catalog, native video controls, URL hash navigation and localStorage for preferences and the watchlist. It loads sample media from W3C and MDN with attribution on each title page.

The publishing branch is `gh-pages` at its root. To update that branch, publish this directory's contents plus `.nojekyll`. The full Next.js app lives in `web/`.
