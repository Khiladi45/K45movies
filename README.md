# K45movies GitHub Pages

This branch contains the generated static site. Build it from the [website source and deployment guide](https://github.com/Khiladi45/K45movies/blob/f5411b54a21e75a9e89db67df8ec62452685355a/web/docs/STATIC_PAGES.md).

The site reads the existing K45movies-api manifest. It provides browser-based anime browsing, Movie Based metadata and YouTube embeds. The full Next.js provider and media routes run in the separate server build.
